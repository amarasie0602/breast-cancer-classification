What the labels mean

“Benign” means a non-cancerous tumour, not healthy tissue. Every image in this dataset comes from a tumour biopsy, so the model has never seen normal tissue. It does not estimate ER, PR, HER2 or triple-negative status, which require immunohistochemistry.
